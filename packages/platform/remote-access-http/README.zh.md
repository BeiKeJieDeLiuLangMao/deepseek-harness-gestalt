# 远程访问 HTTP

[English](README.md) | 中文

公开远程访问服务的 HTTP 消费方。一个固定平台路由接收当前安装的账号证明请求头、校验操作输入，并且只通过 `ctx.remoteAccess` 委派。

消费方不读取账号数据库字段，也不自行授予权限。远程访问提供方会在任何配对生命周期变更前，通过平台账号公开服务鉴别账号、安装标识及安装类型。

## 模型体验

无。HTTP 消费方在模型请求之外处理配对状态。

#### KV Cache 影响

无。

## 已知限制与暂缓事项

- 此路由只拥有个人配对操作；它不转发 Relay 密文或 Host 请求。
- 部署 TLS、限流与审计策略仍由 Platform 组合负责。
