标准模式

完整编码 Agent：文件编辑、Shell、检索、Skills、计划、目标、子代理与工作流。

PTC 模式

标准能力加上 Code Mode SDK，模型用一段 TypeScript 组合多步工具。

极简模式

只留持久 bash 与 str_replace_editor，给最小环境做模型基准。

创造模式

检查运行时、试验 Cordis 插件，并据此组合新的 Agent preset。
