# Triage labels

English | [中文](triage-labels.zh.md)

Matt skills use five canonical triage roles. The GitHub label string equals the canonical role.

| Matt role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue |
| `needs-info` | `needs-info` | Work is waiting for information from the reporter |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified and ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | The work requires human implementation |
| `wontfix` | `wontfix` | The issue will not be actioned |

When a skill names a triage role, use the corresponding GitHub label from this table.
