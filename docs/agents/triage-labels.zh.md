# Triage 标签

[English](triage-labels.md) | 中文

Matt skills 使用五种规范 triage 角色。GitHub 标签字符串与规范角色名称相同。

| Matt 角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估此 Issue |
| `needs-info` | `needs-info` | 等待报告者提供信息 |
| `ready-for-agent` | `ready-for-agent` | Issue 已完整定义，可交给 AFK agent（智能体） |
| `ready-for-human` | `ready-for-human` | 工作需要人工实现 |
| `wontfix` | `wontfix` | 不会处理此 Issue |

当 skill（技能）指定 triage 角色时，使用此表中对应的 GitHub 标签。
