# Agent Note: Repair the inherited baseline CI reds

Status: implemented

English | [中文](2026-08-19-inherited-ci-baseline-reds.zh.md)

## Problem

The delivery baseline carried four independent red lanes that no open pull request caused. First, both lanes that execute the coverage inventory — Linux coverage and native Windows — checked out with the default depth-1 fetch, so the Desktop release-notes test could not resolve its pinned manifest range through the Git graph and failed deterministically on every fresh hosted runner. Second, the Web browser replay suite failed across dozens of scenarios: the recorded aria goldens predated the composer image-intake button, two scroll-contract streams were short enough to exhaust before a loaded CI runner reached the growth assertion, the Desktop chrome scenario's `window.dshDesktop` mock no longer covered the preload surface the Desktop UI plugin binds, and the Models settings section listed only `configured` provider rows — which, after the whole-section occupancy change, made the unkeyed DeepSeek route vanish together with its first-run setup card. The same snapshots-and-artifacts lane also replayed a translation-prompt snapshot that still expected the upstream "DeepSeek Harness" README title, and the two-instance-relay example in `DSH_EXAMPLE_MODE=lib` mapped every provider `RemoteRelayError` to `RELAY_ATTACHMENT_REJECTED` because tsdown emitted a second constructor inside `relay-provider.js`. Third, four Desktop tests asserted POSIX path and mode spellings that cannot hold on a Windows host, and one subagent teardown test relied on the one-second `vi.waitFor` default for an asynchronous settlement warning. The required `all-checks-passed` aggregate follows coverage, snapshots, and the listed `needs`; `windows-native` is an independent check and is absent from `all-checks-passed.needs`.

## Decision

**Coverage lanes fetch full history.** Every `ci.yml` lane that runs an aggregate containing the coverage gates checks out with `fetch-depth: 0`, and a workflow contract test pins those job ids (`node-24-coverage`, `windows-native`, and the other coverage-aggregate jobs) and rejects a shallow checkout, so a renamed or wrapper-scripted job cannot silently leave the full-history set. The release-notes CLI stays offline: verification keeps reading the local Git graph.

**Fixtures follow the product; behavior bugs get fixed.** The composer image-intake button is shipped product surface, so the goldens were re-recorded through the sanctioned refresh mode and the diff was reviewed line by line. The same aria refresh also records two `删除 DeepSeek (deepseek-official)` rows, which ticket #120 occupancy and `removable` semantics surface for the official DeepSeek route. The two ungated scroll-contract streams grew from 120/240 to 960 paced chunks so the stream outlives the slowest CI interaction gap instead of relying on wall-clock luck. Desktop chrome e2e installs `installDesktopBridgeFixture` ([typed DesktopBridge fixture](../testing/2026-08-21-typed-desktop-bridge-e2e-fixture.md)), which implements the complete `DesktopBridge` preload surface with inert `unavailable` account and pairing snapshots. The Models section again lists every mounted whole-section provider — as the open setup card in the first-run posture and as a plain row otherwise — because `configured` now means the user layer occupies the section, which is false exactly when the first-run card must render.

**Desktop tests assert platform semantics.** Icon and runtime-path expectations compute joined paths for the host and expect `node.exe` on Windows; the copy-tree test compares resolved link referents rather than one platform's `readlink` spelling; owner-only mode is asserted only where the platform exposes POSIX mode bits. The teardown-failure observation window widened to the ten seconds its sibling assertions already use.

**Built Relay shares the public error constructor.** The host-only provider imports `RemoteRelayError` from `@deepseek-ai/dsh-remote-access`, and that provider tsdown entry lists the package in `deps.neverBundle`, so the WSS Consumer's `instanceof` check and the provider throw the same class. The translation-prompt snapshot is refreshed from the Gestalt README through the sanctioned snapshot refresh.

**Clearing the shallow-checkout red surfaces the companion baseline's remaining gates.** The Linux coverage lane now finishes its tests and fails the per-file 100% inventory on Gestalt client, schedule, remote-access, and search files that never had a covering lane. Testable Schedule decode/replay/time validation (`domain.ts`, `projection.ts`), the extracted DeepSeek `postSearch` path, and the Models occupancy/`configured`/`removable` store gain owning tests to per-file 100%. Remaining `remote-access` and `*-http`/`*-client` index files stay excluded with `TODO(#168,#170,#171): delete when merged`; other companion UI files stay on the existing `TODO(gui)` list. `revokeCredential` plus the Desktop Account source also gain owning tests. Consumers-lane oxlint and jscpd failures are the same companion surface: deprecated `escape`/`unescape`, unbound input-action methods, untyped `ctx.get('web')`, and cloned snapshot/HTTP/tab/field blocks. Platform Account and Remote Access HTTP JSON parse and error writers share the parameterized helpers on `@deepseek-ai/dsh-host-webserver` ([zero-clone extraction](2026-08-21-zero-clone-duplication-gate.md)). The `pwsh-tool-turn` header sidecar is refreshed to the current sandbox sentence, `job_*` "job" wording, and job-then-pwsh tool order the Linux composition emits. The Schedule board snapshot pins Playwright `timezoneId` to `Asia/Shanghai` (issue #95) so local-time AM/PM is host-independent; the `{{clock}}` normalizer does not swallow the meridian. Workspace-management re-hovers the hover-only row action before a normal click. Assembled-boot jsdom installs a file-scoped in-memory `indexedDB` because Composer persist (`putStagedImage`) can open the database after the test and afterEach have finished; the request helper is unparameterized so oxlint `no-unused-type-parameters` stays clean. The process-exit host-exit suite waits for the host `ready` handshake before reading `tree.json`, because the managed child can publish the tree while `node-pty.spawn` is still blocked in the host; the published record itself is an atomic rename plus a valid-JSON wait ([ticket-rerun handshakes](2026-08-20-ci-ticket-rerun-flakes.md)). The DeepSeek-defaults headless mock writes its first SSE comment when the request arrives, not on `end`.

## Alternatives considered

**Resolve the release-notes range without Git history in the test.** Rejected: the CLI's ancestry check is the product behavior under test, and the verified range is real repository history; the lane, not the assertion, was wrong.

**Trim the scroll-contract assertions instead of lengthening the streams.** Rejected: the growth assertion is the behavior under test — streaming continues while the reader is scrolled away — and shortening the observation would describe a weaker contract.

**Revert the whole-section occupancy change in the Models store.** Rejected: the occupancy semantics for `configured` and `removable` are deliberate and unit-pinned; the defect was the view deriving its listing from `configured` alone.

**Detect Relay failures by `error.name` or `code` instead of `instanceof`.** Rejected: Consumers already branch on the public class, and the provider can share that constructor without changing the HTTP mapping contract.

**Keep importing `RemoteRelayError` from `./relay.ts` and mark `./relay.js` external.** Rejected: the published runtime is `lib/index.js`, not a sibling `lib/relay.js`; Consumers load the class from the public package entry.

**Swallow AM/PM inside the `{{clock}}` normalizer.** Rejected: that hides the timezone fixture bug in issue #95; the Schedule snapshot must declare `timezoneId` and keep product local-time formatting.

**Exclude Schedule domain/projection, DeepSeek `postSearch`, and the Models store from coverage as GUI debt.** Rejected: those files are testable logic this baseline already owns.

## Consequences

Pull requests on this baseline no longer inherit the coverage, snapshots, and native-Windows reds. Native complete stays an independent required check outside `all-checks-passed.needs`. The Models section keeps the setup card reachable for first-run users while preserving the occupancy-based `configured` and `removable` semantics the provider-row rework introduced. The scroll contract's stream length is now a stated sizing contract (`LIVE_STREAM_CHUNKS`) rather than an implicit race. Lib-mode two-instance-relay replay maps `REMOTE_OFFLINE` through one `RemoteRelayError` constructor. The Schedule board snapshot is timezone-stable across hosted UTC and `Asia/Shanghai` hosts (issue #95). The `TODO(#168,#170,#171)` index excludes expire when those PRs merge.
